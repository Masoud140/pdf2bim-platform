## How an entry is reviewed

1. Check the value against an authorised copy of the named Standard. Record the edition and amendment.
2. Set `reference.authorised_source` (which copy), `review.reviewer`, `review.date` and `review.method`.
3. Set the status to `checked` (independent check) or `approved` (responsible engineer).
4. Agents may not set `checked` / `approved`; the loader rejects it.
5. If the code value is wrong, fix the code (and re-run the baseline). Re-running `standards/extract_from_code.py` resets the status of any entry whose code value changed.
